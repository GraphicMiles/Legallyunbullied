Beautiful UI Components Demo

All 9 components adapted from beautifului.dev for Legally Unbullied

1. Loading State (Drive Variant)

Pixel-grid loader with shimmer and elapsed timer

2. Thinking (Tabbed)

Expandable traces with Steps, Reasoning, Search, Coding tabs

3. Streaming Text

Streamed answer with inline sources and follow-ups

4. Approval Card

Human-in-the-loop questions with selectable options

5. Tool Chips

Code edits and tool calls as compact chips

6. Task Rows

Live agent task status — running, failed, completed

7. Context Cards

Retrieved knowledge chunks with their sources

8. Prompt Bar

Composer with @ sources, / commands, model picker

Try typing @ or / to see mentions and commands

9. Recommendation Card

Agent suggestion with a confidence meter and actions
