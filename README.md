# Legally Unbullied

Evidence-grounded Nigerian legal-information assistant.

## Documentation

The complete and canonical repository documentation is maintained in one file:

**[`docs/SYSTEM_REFERENCE.md`](docs/SYSTEM_REFERENCE.md)**

It includes setup, environment variables, deployment, repository structure, every API endpoint, the complete agent pipeline, providers, retrieval, citation controls, background worker, browser application, persistence, Firestore rules, corpus/ingestion status, testing, evaluation, security, privacy, current limitations, completed features, and roadmap priorities.

## Quick start

```bash
npm install
npm start
```

Open `http://localhost:3000`.

Run deterministic tests:

```bash
npm test
```

> Legally Unbullied provides legal information, not legal advice.
